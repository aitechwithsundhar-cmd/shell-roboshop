# Roboshop — Shell Scripting Deployment 🐚

Full deployment of Roboshop microservices e-commerce application
using Shell (Bash) scripting on AWS Linux servers.

## Services Deployed
- MongoDB, Redis, MySQL
- RabbitMQ, Nginx
- Node.js microservices
